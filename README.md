BRACKSHU ORBIT is a small interactive space simulation project where you can experiment with gravity and velocity and see how they affect the movement of objects in space.
Features
Interactive space simulation
Adjustable gravity settings
Adjustable velocity settings
Real-time changes in planetary motionSimple and easy-to-use interface
Built With
HTML
CSS and javascript

About the Project :)

I built this project to explore space physics while improving my coding skills. I wanted to create something interactive where users could actually experiment with different settings instead of just reading about them.
Status
Still a work in progress. More improvements and features may come in the future.
